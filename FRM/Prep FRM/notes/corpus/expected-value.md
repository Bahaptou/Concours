The expected value is the **weighted average of the possible outcomes** of a [[random-variable]], where the weights are the probabilities that the outcomes will occur. The mathematical representation of the expected value of random variable X is:

![[expected-value.png|500]]

The Expected Value is a [[linearity]] function. It has both properties :

[[homogeneity]]
E(cX) = cE(X)

[[additivity]]
E(X + Y) = E(X) + E(Y)
